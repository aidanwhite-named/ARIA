# 이월 재시도 및 최종 예산 상태 수정

## 수정

- 실패/부분 성공한 검색은 별도의 고정 목록으로 보존한다. 동일 요청의 재시도
  성공 결과가 과거 빈 목록에 가려지지 않는다. 실패 목록의 미전달 후보도 잃지 않는다.
- 정상적인 검색 채널 생략은 오류와 구별한다. 캐시는 기존처럼 실제 오류가 있는
  조회를 재사용하지 않는다.
- 구성·문헌별 미전달 건수는 실제 고정 목록의 잔여 후보 수로 집계한다.
  실패 채널은 같은 요청의 최신 결과로 대조하며 다른 검색 요청의 실패는 유지한다.
- `budget_limited`는 실행 중 제한을 만난 이력이다. `budget_exhausted`는 현재
  남은 작업·미전달 페이지 또는 회차 상한으로 마무리하지 못한 상태를 뜻한다.
- 근거 패키지의 부분 페이지, 제외 페이지, 패키지 축소가 남으면 최종 예산
  경고는 유지한다. 중간 이월을 모두 해결한 실행의 경고만 해제한다.
- 검색 회차 및 입력 상한, 의미 검색 설정, 보고서 판단은 변경하지 않았다.

## 보관 실행 재생에서 확인한 조건 차이

`c1087b81-51d8-464c-a3d6-5071d917c360`의 원본 인덱스를 읽기 전용으로 열고
보관된 5개 모델 응답을 실행했다. 실제 AI 호출 및 보고서 재생성은 하지 않았다.
요청과 결과 처리는 실제 agent.run 경로로 실행했다. 과거 응답이므로 새 payload에
대한 모델의 반응을 측정하는 실험은 아니다. 재생의 청구항 문자열은 검증용 표시이며,
원래 입력 토큰 수나 보고서 품질의 동등 비교로 사용하지 않는다.

| 조건 | 고정 후보 | 전달 | 남은 후보 | 미처리 요청 | 열람 |
|---|---:|---:|---:|---:|---:|
| 원래 실행과 같은 의미 검색 활성 | 232 | 92 | 140 | 28 | 8쪽 |
| 의미 검색 비활성 대조군 | 67 | 67 | 0 | 0 | 8쪽 |

비활성 대조군에서 이전에 보고된 67건 전부 전달/미처리 0건과 같은 수치가
재현됐다. 이전 재생 스크립트가 없어 그 실행 조건을 단정할 수는 없지만,
해당 0건 결과를 원래 의미 검색 활성 조건의 개선 증거로 사용할 수는 없다.
실제 사용자 설정의 의미 검색은 끄지 않았다.

두 재생 모두 마지막 모델 응답의 finalize가 이월 때문에 보류된 뒤 마지막
실행기 단계에서 결과를 전달하고 회차가 끝났다. 그러므로 대조군도 미처리 0건만으로
검색 마무리까지 완료한 것으로 판정하지 않는다. 추가 AI 호출을 몰래 수행하거나
회차를 늘리지 않았다. 원래 조건의 재생에는 ATT-03 6쪽 제외 및 ATT-04 6쪽
부분 수록도 남았다.
